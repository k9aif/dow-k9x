# CAPABILITY DEVELOPMENT DOCUMENT (CDD) FOR SHADOWLANCE INCREMENT 1

**Document Status:** Final

## 1. Capability Discussion

(S//NF) This program addresses the capability gap for long-range maritime
strike identified in the Initial Capabilities Document for Distributed
Maritime Operations.

(U) The system shall integrate with existing fleet command and control
networks and deliver target-quality track data within the latency
thresholds below.

| Parameter | Threshold | Objective |
|---|---|---|
| Range | 500 nm | 750 nm |
| Track latency | < 5 s | < 2 s |
