Notes:

- Publisher pages are the sites named in each document or recorded in the DAS process model

- Government sites often block scripted downloads; open the publisher pages in a browser.
- S7 (the 7 Nov 2025 "Transforming the Warfighting Acquisition System" memo) is listed in
  [`docs/process-model-2026/01_sources_and_findings.md`](../../../process-model-2026/01_sources_and_findings.md)
  but was not obtained, and DAS does not use it.
